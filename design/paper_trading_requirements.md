## 1. 해결하려는 문제와 사용자 가치

사용자는 분석을 읽는 것에서 더 나아가 자신의 판단대로 투자해 보고, 결과를 통해 판단을 연습하고 싶다. 실제 자금을 사용하지 않는 모의투자로 이 경험을 제공한다.

핵심 목표는 사용자가 직접 매매 여부와 투자 규모를 판단하고, 보유 중 변화와 이후 결과를 돌아보는 것이다. 자동으로 높은 수익을 내거나 AI 분석의 정확성을 수익률 하나로 입증하는 것을 목표로 확정하지 않는다.

초기에는 현재 시장 데이터를 이용하여 실제 시간 경과에 따라 진행하는 모의투자를 제공한다. 과거 데이터를 빠르게 재생하는 연습은 초기 범위에 포함하지 않는다. 이 범위 정의가 무지연 시세나 특정 갱신 간격을 보장하는 것은 아니다.

## 2. 사용자와 시스템 경계

| 구분 | 역할 |
| --- | --- |
| 주 액터: 사용자 | 투자 연습의 매매 판단과 결과 확인 |
| 외부 시스템: 금융정보 제공 시스템 | 분석·평가에 필요한 시장 자료 제공 |
| 대상 시스템 | Stock Agent의 개인 PC 서버와 모바일 클라이언트를 포함한 서비스 |

개인 PC의 처리기·저장소는 내부 요소이며 외부 액터로 두지 않는다. 기존 AI·알림 연동은 기존 서비스의 맥락이며 모의 매매 때마다 AI 실행을 요구하지 않는다.

기존 개인 PC·Android 이용 방향을 유지하고, 향후 중앙 서버로 이전하더라도 모바일 경험을 유지하려는 방향을 따른다. 기존 종목 분석의 공통 결과 정의와 개인 실행 결과의 소유·공유 범위는 변경하지 않는다. 관련 배포 논의는 [#42](https://github.com/PhilPark-geosr/stock-agent/issues/42)를 참고한다.

## 3. 유스케이스 개요 — Inception

다음은 사용자와 논의하여 정리한 유스케이스의 간략한 개요다. 완전한 유스케이스 명세가 아니며, 트리거·사전조건·상세 흐름·예외·성공 보장은 Elaboration에서 구체화한다. 개별 화면 조작이나 내부 처리 단계를 독립 유스케이스로 만들지 않는다.

### UC-PT-01 — 투자 연습을 시작한다

- 주 액터: 사용자
- 개요: 사용자가 초기 가상 자금을 정하고 새로운 투자 연습을 시작한다.
- 적용 조건: 초기 자금은 사용자가 지정하며, 진행 중인 연습은 하나로 한다.
- 관련 요구사항: FR-PT-016·017·020. 관련 초기 초안: FR-PT-001.

### UC-PT-02 — 주식을 가상 매수한다

- 주 액터: 사용자
- 개요: 사용자가 직접 판단한 종목과 수량을 자신의 연습 자금으로 가상 매수한다.
- 적용 조건: 사용자가 관심 종목에 등록한 국내 주식에 한정하고, 보유 현금 범위에서 매수한다.
- 관련 요구사항: 매수 대상 FR-PT-014, 현금 한도 FR-PT-011, 추가 매수·복수 종목 운용·가격 조회 및 재확인 FR-PT-018·019·022·025. 관련 초기 초안: FR-PT-003·004.
- 상세화 시 참조: 가격 조회 실패·오래된 가격의 매매 차단은 기존 FR-PT-025의 예외 조건을 따른다. 이번 개요에서 상세 흐름이나 새로운 체결 정책을 확정하지 않는다.

### UC-PT-03 — 주식을 가상 매도한다

- 주 액터: 사용자
- 개요: 사용자가 보유 주식의 일부 또는 전부를 가상 매도한다.
- 적용 조건: 보유 수량 범위에서 매도하며, 관심 종목에서 삭제된 보유 주식도 매도할 수 있다.
- 관련 요구사항: 복수 종목 운용의 상위 근거 FR-PT-019, 보유 수량 한도 FR-PT-011, 부분 매도 FR-PT-018, 관심 종목에서 삭제된 보유분의 매도 FR-PT-015, 매매 시 가격 재확인 FR-PT-025. 관련 초기 초안: FR-PT-003·004.
- 상세화 시 참조: 가격 조회 실패·오래된 가격의 매매 차단은 기존 FR-PT-025의 예외 조건을 따른다. 구체적인 체결 방식은 별도로 정한다.

### UC-PT-04 — 종목의 현재 가격을 확인한다

- 주 액터: 사용자
- 개요: 사용자가 관심 종목이나 보유 종목의 현재 가격을 확인하여 투자 판단에 참고한다.
- 적용 조건: AI 분석을 실행하지 않아도 확인할 수 있으며, 관심 종목에서 삭제한 보유 종목도 포함한다. 현재 가격의 허용 지연은 시세 공급 검증 후 구체화한다.
- 관련 요구사항: 가격 조회 FR-PT-022, 보유 종목 조회 대상 FR-PT-023, 조회 중 자동 갱신 FR-PT-024.
- 범위 구분: 사용자가 가격 확인을 목적으로 이용하는 유스케이스다. 매매 처리 중 가격을 재확인하는 FR-PT-025는 매수·매도 유스케이스 안의 동작으로 유지한다.

### UC-PT-05 — 가상 포트폴리오 현황을 확인한다

- 주 액터: 사용자
- 개요: 사용자가 진행 중인 투자 연습의 현금, 보유 종목과 수량, 자산 평가액 및 손익을 확인한다.
- 적용 조건: 평가손익과 실현손익을 구분하고, 관심 종목에서 삭제된 보유 주식도 포함한다. 보유 주식의 평가에 사용한 가격과 해당 가격의 기준 시각을 확인할 수 있어야 한다.
- 가격 시각의 의미: 평가에 사용한 가격 자체의 기준 시각이며, 가격을 조회하거나 화면을 확인한 시각과 구분한다. 종목마다 가격 기준 시각이 다를 수 있으므로 전체 자산이 동일 시각의 가격으로 평가됐다고 가정하지 않는다.
- 관련 요구사항: 자산 현황 초안 FR-PT-005, 손익 확인 초안 FR-PT-006, 가격 기준 시점 초안 FR-PT-008, 관심 종목에서 삭제된 보유분 조회 FR-PT-015, 보유 종목 가격 조회 FR-PT-023, 자동 갱신 FR-PT-024.
- 상세화 시 참조: 평가 가격의 선택 기준·허용 지연과 일부 종목의 가격 조회 실패 시 전체 평가의 표시 방식은 별도로 정한다. 이번 개요에서 새로운 가격 정책을 확정하지 않는다.

### UC-PT-06 — 투자 연습 기록을 확인한다

- 주 액터: 사용자
- 개요: 사용자가 투자 연습의 과거 매수·매도 내역과 선택적으로 남긴 매매 이유, 결과를 확인한다.
- 적용 조건: 진행 중인 연습의 이전 매매와 종료된 연습 기록을 확인할 수 있다. 매매 이유를 기록하지 않았어도 조회할 수 있으며, 종료된 연습은 종료 당시 보존된 자산·평가 결과를 제공한다.
- 관련 요구사항: 매매 이력 조회 초안 FR-PT-007, 선택적 매매 이유 기록 FR-PT-009, 이전 연습 기록 보존 FR-PT-017·020·021.
- 범위 구분: 기존 기록을 사용자가 돌아보는 범위로 시작한다. AI가 투자 판단을 평가하거나 조언하는 기능은 이번 유스케이스에 포함하지 않는다. 진행 중인 연습의 현재 자산 현황 확인은 UC-PT-05에서 다룬다.

## 4. 합의된 상위 요구사항과 초기 범위

기존 ID와 합의 날짜를 유지한다. 상세 정책을 별도 문서로 옮겨도 합의는 유효하다.

기존 FR-PT-010은 2026-10-26 검토에서 독립 기능보다 제품 목적·초기 범위에 해당한다고 판단하여 1절로 재분류했다. 2026-10-19의 방향 합의는 유지하며, 해당 ID는 변경 이력용으로만 남기고 다른 요구사항에 재사용하지 않는다.

| ID | 상위 요구사항 | 근거 |
| --- | --- | --- |
| FR-PT-011 | 초기 모의투자는 보유 현금 범위에서만 매수를 허용하고, 보유 수량 범위에서만 매도를 허용한다. 차입·레버리지 매수와 공매도는 초기 범위에서 제외한다. | 2026-10-19 사용자 확인 |
| FR-PT-014 | 초기 가상 매수는 사용자가 관심 종목에 등록한 국내 주식에 한해 허용한다. | 2026-10-19 사용자 확인 |
| FR-PT-019 | 사용자는 하나의 연습에서 동일한 가상 자금을 활용하여 여러 종목을 매수·보유·매도할 수 있어야 한다. | 2026-10-19 사용자 확인 |
| FR-PT-022 | 사용자는 관심 종목과 보유 종목의 현재 가격 정보를 조회할 수 있어야 한다. | 2026-10-26 사용자 확인 |

관심 종목 제한은 매수 대상에 적용한다. 이미 보유한 종목을 관심 종목에서 삭제한 경우의 조회·매도·가격 조회는 상세 정책 FR-PT-015·023을 따른다.

### FR-PT-022 적용 조건

- 가격 조회를 위해 AI 분석 실행이나 완료를 요구하지 않는다.
- 현재 가격의 허용 지연은 시세 공급 검증 후 구체화한다. ‘현재 가격’이라는 표현만으로 무지연 시세가 확보되었다고 보지 않는다.
- 화면을 보는 동안의 자동 갱신은 상세 요구사항 FR-PT-024에서 다룬다.

### 후속 확장과 현재 필수 범위 밖

| 구분 | 내용 | 상태 |
| --- | --- | --- |
| 후속 확장 목표 | 국내 주식 모의투자 이후 미국 주식 모의투자로 확장한다. | 2026-10-19 방향 합의. 일정·상세 정책 미정 |
| 초기 방식으로 선택하지 않음 | 과거 시장을 재생하는 연습 | 현재 시장 방식으로 합의 |
| 초기 필수 범위 밖 | 화면을 닫은 동안의 상시 가격 수집·시간별 자산 변화 이력 | 화면 조회 중 갱신과 매매 시 재확인으로 합의 |
| 후속 작업으로 보류 | 증권사 계정·시세 API 연결 절차의 구체화·구현 | 사용자 요청. 공급자 채택을 뜻하지 않음 |
| 이번 목표에 포함하지 않음 | 실제 거래 주문 전송 | 가상 자금으로 직접 판단을 연습하는 범위 |
| 미채택 후보 | 자동매매·자동 감시 주문·순위 경쟁 | 초기 기능으로 채택하지 않음 |

미국 주식 확장 일정과 상세 정책은 미정이다.

## 5. 초기 검증의 성공 기준 — 제안, 미합의

다음은 제품의 유용성을 확인하기 위한 관찰 기준이며 성능 수치나 출시 승인 기준으로 확정하지 않았다.

- 사용자가 모바일에서 분석과 가격의 기준 시점을 이해하고, 스스로 가상 매매를 결정할 수 있는가?
- 사용자가 여러 종목의 보유 상태와 평가손익·실현손익을 구분하여 자신의 투자 결과를 이해할 수 있는가?
- 사용자가 선택적으로 남긴 매매 이유와 이후 결과를 보고 판단을 돌아볼 수 있는가?
- 개인 PC 연결과 시세 조회의 제약을 사용자가 이해하며 연습을 이어갈 수 있는가?

목표 사용자 수·검증 기간·정량 기준은 미정이다. 수익 발생만으로 서비스 성공이나 판단의 타당성을 단정하지 않는다.

## 6. 실행 가능성과 핵심 위험

| 위험·불확실성 | 현재 근거와 한계 | 다음 확인 |
| --- | --- | --- |
| 매매에 적합한 가격 확보 | 기존 코드는 일봉 중심. 두 종목의 1분봉 응답은 확인했으나 장중 지연·정확성·안정성 미검증 | 사용 가능한 시세의 최신성·누락·비용·이용 조건 확인 |
| 개인 PC·모바일 연결 | 기존 배포 방향을 계승하나 모의투자 흐름의 실기기 검증은 아직 없음 | 연결 실패·재연결 시 사용자가 결과를 오인하지 않는지 확인 |
| 코드 재사용 범위 | 로그인·관심 종목·공통 분석·종목 식별의 기반 존재. 모의 매매·잔고·이력은 새 기능 필요 | 우선 핵심 흐름의 재사용 경계 확인 |
| 연습의 유용성 | 수동 매매와 회고를 원한다는 사용자 의도 확인 | 성공 기준 합의 후 대표 흐름의 사용성 검증 |

기존 저장 분석의 가격을 매매 시점의 현재가로 재사용할 수 있다고 보지 않는다. AI와 독립적인 가격 조회는 합의된 방향이며 공급자·세부 동작은 후속 구체화 대상이다. 데이터 공급 조건이 현재 시장 연습 목표를 충족하지 못하면 대안을 사용자와 논의한다.

## 7. 다음 단계 진입을 위해 남은 일

아래는 작업 순서 제안이며 새로운 승인 절차가 아니다. 이미 합의한 범위를 다시 승인받지 않는다.

1. 핵심 사용자 목표와 성공 기준 제안을 검토한다.
2. 범위를 좌우하는 시세·연결 위험에 대해 다음 검증 항목과 우선순위를 정한다. API 연결 절차 구현을 지금 시작한다는 뜻은 아니다.
3. 이후 대표 유스케이스의 OOA와 예외를 구체화한다. 모든 상세 정책을 Inception에서 확정할 필요는 없다.
4. OOA 합의 후 도메인 모델 → 관계 중심 시퀀스 → 상세 클래스 순서로 진행하고 요구사항과 추적한다.
