신규상장 확인새 종목 식별값과 효력 시점·상장 상태를 게시합니다. 검색 기능이 이 정보를 읽어 등록 후보를 결정합니다.
상폐 근거 확인상태와 효력 시점을 제공합니다. 검색·알림 기능이 신규 작업 허용 여부를 판단하며, 갱신은 기존 문서를 지우지 않습니다.

같은 코드가 새 회사에 재사용됨새 종목으로 구별합니다. 과거 회사의 브리핑을 새 회사로 옮기지 않습니다.

기존 알림을 상폐 후 자동 종료하거나 복원하는 정책은 별도입니다. 이번 갱신이 기존 조건을 삭제하지는 않습니다.

두 기능은 무엇을 주고받나요?

갱신 기능은 종목 식별값·이름·시장·상태·검증된 별칭과 기준 시점·게시 버전·자료 이용 상태를 제공합니다. 검색 기능은 이를 읽어 목적에 맞는 후보를 보여줍니다.

갱신 중에도 검색은 직전의 정상 자료가 있으면 읽습니다. 유효 자료가 없으면 정상 0건 대신 이용 불가 상태를 제공합니다. 관심종목 소유권, 알림 조건 저장, 과거 브리핑 조회는 각각의 기능에서 처리합니다. 같은 DB를 쓴다고 같은 기능은 아닙니다.
